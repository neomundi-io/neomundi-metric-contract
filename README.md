# NeoMundi Metric Contract

**Version:** 0.0
**Status:** Draft
**Maintainer:** NeoMundi
**Scope:** Runtime measurement of AI systems

[🇬🇧 English](#english) · [🇫🇷 Français](#français)

---

## English

The **NeoMundi Metric Contract** defines the semantic boundary of a NeoMundi runtime measurement.

It specifies how a measurement is identified, interpreted, versioned and associated with its declared observation conditions.

The Metric Contract describes the **measurement layer**.

It does **not** define the policy decision or operational action that an external system may derive from that measurement.

> **NeoMundi measures. External systems decide what to do with the measurement.**

### Metric Contract v0.0

→ [Read the English version](./metric-contract-v0.0.en.md)

### Scope

The contract currently covers the principles required to describe:

* metric identity and versioning;
* measured object and observable property;
* measurement conditions;
* measurement protocol;
* machine-readable measurement values;
* measurement semantics;
* metrological states;
* threshold references;
* measurement coverage;
* limitations;
* traceability;
* interoperability boundaries;
* infrastructure neutrality.

### Draft status

Version **0.0** is an initial semantic specification.

Its machine-readable representation may evolve as the **NeoMundi Runtime Interoperability Contract** is formalized.

The objective of this version is therefore to establish the meaning and boundaries of the NeoMundi measurement layer before freezing its interoperable representation.

## Français

Le **NeoMundi Metric Contract** définit la frontière sémantique d'une mesure runtime NeoMundi.

Il précise comment une mesure est identifiée, interprétée, versionnée et associée aux conditions déclarées dans lesquelles elle a été produite.

Le Metric Contract décrit la **couche de mesure**.

Il ne définit **ni la décision de politique ni l'action opérationnelle** qu'un système externe peut dériver de cette mesure.

> **NeoMundi mesure. Les systèmes externes décident quoi faire de la mesure.**

### Metric Contract v0.0

→ [Lire la version française](./metric-contract-v0.0.fr.md)

### Périmètre

Le contrat couvre actuellement les principes nécessaires pour décrire :

* l'identité et le versionnement d'une métrique ;
* l'objet mesuré et la propriété observable ;
* les conditions de mesure ;
* le protocole de mesure ;
* les valeurs de mesure exploitables par machine ;
* la sémantique de la mesure ;
* les états métrologiques ;
* les références de seuils ;
* la couverture de mesure ;
* les limites ;
* la traçabilité ;
* les frontières d'interopérabilité ;
* la neutralité vis-à-vis de l'infrastructure.

### Statut Draft

La version **0.0** constitue une première spécification sémantique.

Sa représentation exploitable par machine pourra évoluer avec la formalisation du **NeoMundi Runtime Interoperability Contract**.

L'objectif de cette version est donc d'établir la signification et les frontières de la couche de mesure NeoMundi avant de figer sa représentation interopérable.
